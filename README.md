## Basic projects that will help you learn Python
### 1. CLI Calculator
#### Basic CLI Calculator with functions like:
    - Adding numbers,
    - Substracting numbers,
    - Multipling numbers,
    - Dividing numbers,
    - Square root,
    - Exponentiation,
    - History of operations
### 2. CLI To Do App
#### To Do App with ability to:
    - Save tasks in SQLite,
    - Create, Read, Update, Delete (CRUD)
    - Deadlines and Priorities
### 3. Guess a number game
#### Game where you have to guess the drawn number
    - Scoreboard with your statistics
    - Average score
    - 3 levels of difficulty
    - Total games played
### 4. Finance Manager
#### CLI that helps you with finance managment
    - Add incomes and expenses
    - See your monthly revenue
    - Charts to help you analyze your expenses
    - Monthly Telegram report with analysis
